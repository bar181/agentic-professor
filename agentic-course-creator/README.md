## Core Parameters

Configure the overall voice and lesson-specific emphasis:

```yaml
# Core parameters for persona tuning
voice_parameters:
  overall_tone: "professional_friendly"  # Options: academic, casual, professional_friendly
  formality_level: 0.7                   # 0 = very casual, 1 = very formal

  # Lesson-specific emphasis (same prof, different modes)
  lesson_personas:
    captivate:                           # Lesson 1
      energy: 7                          # 1-10 scale
      analogy_frequency: "high"          # low, medium, high
      visionary_thinking: true
      hook_style: "contrast"             # frustration, contrast, question

    orient:                              # Lesson 2
      energy: 5
      example_depth: "progressive"       # basic, progressive, advanced
      definition_precision: "high"
      code_commenting: "extensive"

    realize:                             # Lesson 3
      energy: 6
      storytelling_style: "compassionate"
      humor_level: "light"               # none, light, moderate
      human_impact_emphasis: true

    execute:                             # Lesson 4
      energy: 4
      guidance_level: "structured"       # minimal, structured, detailed
      error_demonstration: true
      recovery_paths: true

  # Default persona (Bradley Ross style for Lesson 4)
  default_execute_persona:
    name: "Bradley Ross"
    characteristics:
      - "Direct and practical"
      - "Shows mistakes and recovery"
      - "Focuses on 'here's what to do'"
      - "Supportive without hand-holding"
```

## Quick Start Examples

### Example 1: Adapt for New Audience
```bash
# Take marketing course, create version for manufacturing
acc adapt \
  --source courses/ai-for-marketing/ \
  --new-audience "manufacturing engineers" \
  --adapt-components "problem-sets,case-studies" \
  --output courses/ai-for-manufacturing/
```
**Time:** ~5 minutes

### Example 2: Create from Documentation
```bash
# Turn product docs into a course
acc create \
  --source ./product-readme.md ./api-docs/ \
  --topic "Mastering ProductX" \
  --audience "developers" \
  --level "intermediate" \
  --output courses/productx-mastery/
```
**Time:** ~10 minutes for full course draft

### Example 3: Modernize Legacy Course
```bash
# Update old slides to modern format
acc modernize \
  --source ./old-course-slides.pptx \
  --update-examples 2024 \
  --add-problem-sets \
  --output courses/modernized-course/
```
**Time:** ~15 minutes

### Example 4: Quick Edit and Regenerate
```bash
# Regenerate one lesson with new direction
acc edit \
  --course courses/ai-course/ \
  --module 2.1 \
  --lesson 3 \
  --feedback "Add more humor, use healthcare example instead" \
  --regenerate
```
**Time:** ~1 minute
