# AMCD: The CORE + FLEX Model
## Adaptive Modular Course Design — One-Page Summary

---

## The Problem

Traditional course design forces a choice: create one course that's too hard for beginners or too easy for experts, OR create multiple courses that duplicate effort and fragment quality.

## The Solution: CORE + FLEX

**Separate what stays constant from what adapts.**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│        CORE                    +              FLEX          │
│      (Stable)                              (Adaptive)       │
│                                                             │
│   C - Captivate                        F - Fit              │
│   O - Orient                           L - Level            │
│   R - Realize                          E - Equivalent       │
│   E - Execute                          X - eXpand           │
│                                                             │
│   = 4 Lessons                          = Tiered Problem     │
│     for ALL                              Sets by AUDIENCE   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## CORE: Four Lessons Every Learner Experiences

| Lesson | Purpose | Energy | Question Answered |
|--------|---------|--------|-------------------|
| **C**aptivate | Hook with story & relevance | High | "Why should I care?" |
| **O**rient | Build understanding systematically | Moderate | "How does it work?" |
| **R**ealize | Show real-world impact (case study) | Warm | "What happens when...?" |
| **E**xecute | Practice hands-on with guidance | Focused | "Can I do this?" |

**Same story. Same concepts. Same case study. For everyone.**

---

## FLEX: Problem Sets That Adapt

| Principle | Meaning | Implementation |
|-----------|---------|----------------|
| **F**it | Match to learner | Difficulty appropriate to skill level |
| **L**evel | Offer tiers | 2-3 options (Less / Standard / More) |
| **E**quivalent | Same effort | 45 min for beginner on "Less" = 45 min for expert on "More" |
| **X**pand | Scale up | Module → Pathway → Course |

**Different scope. Same time investment. Fair for all.**

## The One-Liner

> *"AMCD separates what every learner needs (CORE) from what different learners practice (FLEX)."*

## How It Scales

```
MODULE (1-2 hours)          PATHWAY (3-4 modules)       COURSE (3-4 pathways)
├─ CORE (4 lessons)         ├─ Mini-arc                 ├─ Major arc
└─ FLEX (problem sets)      └─ Pathway project          └─ Capstone project
```

## Get Started in 3 Steps

1. **Write the CORE**: Create 4 lessons (Captivate → Orient → Realize → Execute)
2. **Design the FLEX**: Build 2-3 problem set tiers for your audience
3. **Validate time equivalence**: Ensure each tier takes similar time at its target level
